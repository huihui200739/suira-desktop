# 0.2.22 材质层次与像素伙伴

## 本轮落实

保留既有键位排列、工具图标、名字和字母角标。雾灰托盘使用独立的 94%/87%/98% 三档遮挡，乳白空键与更亮的功能键拥有各自填充、下缘和接触阴影。底板切档不再让空键一起消失。240ms 的窄幅单次反光用于全部键位，工具取自身色，空键使用银白；立即轻抬、40ms 后倾斜和重入限频保留。

内置生图工具生成原创“小信”透明四姿态图集，随安装包离线提供。伙伴接入工作台、悬浮板、Markdown、日历、剪贴板和速记。配色（暖橘/薄荷）、32/40 大小、安静模式和显示开关可持久化并即时同步；Markdown 紧凑顶栏自动缩小。关闭后能从通用与外观重新开启。活动窗口唤起或鼠标接近时挥手，短暂眨眼；实际文档/速记保存成功后举信。其他窗口静止，失焦/隐藏清理定时器，尊重减少动态效果，不持续循环。截图框和钉图内容不叠加角色，防止遮挡采集和用户图片。

## 素材

使用内置 image_gen，原图保存在 [companion-courier.png](../src/art/companion-courier.png)，未重画为 SVG 占位图。四格逐帧由 CSS 显示，透明 alpha 保留。生成方式、原始提示词及实际尺寸见 [素材记录](design/companion-generation.md)。

## 集中验证

- material-companion-check：实际 Electron 六类窗口、图集加载与 alpha、设置同步、尺寸/配色/隐藏、安静和减少动态效果通过。
- 白色背景下空键与托盘平均通道差分别为柔和 40、通透 37，均大于 25；见 [量化记录](material-companion-verification.json)。这是当前页面采样值，不是通用对比度保证。
- controls-only：240×200 最小速记窗口菜单在边界内；真实设置持久化、隐藏/恢复和实际写入后举信反馈通过。
- flow-only：空键进入后播放单次 240ms 反光通过。
- core：39 项通过；notes-check：40 项通过，包含保存失败与最小窗口。
- panel-shot --check：键位绑定、拖动、错误路径、四组尺寸/主题及三档实际鼠标扫过全部通过；新指标见 [动效记录](keycap-motion-verification.json)。
- verify:workspace：文档和日历保存、导出、重载、编辑保护等真实流程通过。
- 安装包 CRC、103 个生产文件逐字节匹配、feed 与 SHA512 一致。见 [发行清单](release-0.2.22.json)。

仅做与本次改动匹配的集中检查，未重复运行上一轮全部原生窗口和安装生命周期套件。

## 原生模糊边界

沿用 0.2.21 已实测的圆角安全门槛：当前 accent blur 会越过圆角区域，因此本版不重新启用这条路径。磨砂层次使用明确的填充、遮挡与键帽体积建立，不声称实现了实时桌面背景模糊。此前失败路径的桌面证据见 [圆角核对](corners-and-updates-0.2.21.md)。

设计方法沿用 Damir Sokolovsky 的 [unslop](https://github.com/heydamir/unslop)（CC BY 4.0），视觉与伙伴方向由用户确认。

后续安装版复核发现日历伙伴位于隐藏标题区域，此项已在 0.2.23 修正；不能将早期“DOM 存在”的检查视作可见性通过。最终交付以 [0.2.23](material-companion-0.2.23.md) 的真实尺寸与视口检查为准。
