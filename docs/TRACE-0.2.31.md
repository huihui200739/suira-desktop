# 0.2.31 处理轨迹第一版

以来源内容为入口，收紧统计，按需展开步骤、尝试和用时。沿用工作台的中性色与蓝色强调，不复制付费组件源码，不引入 React 运行时。信息组织参考 affectUI 的 Agent Inbox、Tool Call Card 和 Trace Waterfall 公开说明。

通过 inputIds、outputIds 和内容 parentIds 建立关系；同名记录不参与归组。读取现有记录，不迁移、不覆盖数据。循环关系通过并查集处理，没有输入或输出的记录保持独立。最多读取已保留的 500 次处理，分批显示内容组。

相同动作与相同输入的执行归为一个步骤，多次尝试按时间保留。当前状态取该步骤最近一次尝试；只有相应步骤成功才消除其待处理状态，后续复制不会掩盖失败的翻译。分组状态优先显示运行中，再显示未解决的失败。耗时来自真实开始、完成时间，包含重试，不含用户操作间隔；没有可靠时间时显示“—”。

操作详情使用内容预览与可读错误，隐藏不相关的技术参数。原内容已清理时保留处理记录并禁用重试。翻译步骤提供调整翻译及服务设置入口，沿用独立翻译窗口。操作开始时广播状态，计时只更新数字；刷新保留展开状态与键盘焦点。

验证：分组模型测试覆盖同名隔离、输入输出关系、重试恢复、未解决的失败、删除、循环、缺失时间与只读输入；真实 Electron 隔离数据检查覆盖原文预览、调整翻译、真实本地重试、展开保持、筛选搜索、深浅主题及窄窗口。截图为虚构示例资料。详细结果见 trail-0.2.31.json。
