# 0.2.24 交付记录

本轮按用户最终选择交付原生实时玻璃，撤去静态壁纸底景。六类主要窗口共用 `src/liquid-glass.css` / `.js`。内容阅读面保持高不透明度，控件与键帽独立于背景分层；所有设置页和工作台各分区沿用这些令牌。

Windows 11 使用透明的 Chromium 内容层、DWM 全客户区框架、系统圆角和原生 accent blur。此路径不调用 `setShape`，避免系统模糊越过手工圆角区域；其他浮层继续使用原有 alpha 裁剪。普通窗口使用系统 8 DIP 圆角，最大化及全屏使用直角。透明窗口通过工作区边界实现最大化与恢复，保留正常尺寸，适配任务栏与负坐标显示器。

系统真实背景随外部窗口变化。没有壁纸替代、循环抓屏或桌面内容上传。网页配方中的 SVG 仅能处理网页内容，故不对外部窗口宣称实时折射。

验证：

- `tools/native-glass-live-check.js` 在隔离配置、合成背景窗口上检查悬浮板、工作台、日历、Markdown：红蓝背景变化真实透入，2px 条纹模糊，四个角的实际桌面合成像素与裸背景对照。证据见 `native-glass-0.2.24.json`。预览图片中的渐变来自位于应用后方的测试窗口，不是应用内壁纸。
- `tools/electron-surface-check.js` 检查独立窗口、原生圆角、调整大小、最大化及恢复、任务栏避让。
- 原生 API、窗口几何、最大化状态、工作台 CRUD、UI/API 接线、页面渲染、键位绑定和更新控制器检查通过。
- 发布包的 107 个源码/资源文件逐字节匹配，安装包 CRC、SHA256/SHA512、内置更新源和 blockmap 通过检查。打包程序在独立临时路径以隔离配置实测，工具图标、伙伴可见边界、快速悬停、原生玻璃与纯色切换通过检查。
- 自定义 Electron 运行时中遗留的 `udata` 缓存和 `debug.log` 在打包阶段移除；原始运行环境及真实用户配置保留。
