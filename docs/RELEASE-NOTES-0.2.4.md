# 随序 SUIRA 0.2.4

让快捷键按你的习惯工作，让 Markdown 从桌面自然打开。

## 这次更新

- **先由你决定，再响应全局按键。** 全局快捷键默认关闭，开启前说明影响。设置中可检查本软件键位的当前注册占用；冲突会提示改键，不强制抢占。
- **更明确的快捷键规则。** 专用唤起键保持原配置，重复派生键停用；Ctrl+A/C/V 等编辑操作保留，输入框与输入法优先处理面板输入。
- **随序也能打开本地 Markdown。** 支持 `.md` / `.markdown` 的 Windows「打开方式」候选、中文路径及程序已运行时再次打开。
- **草稿与原文件，各有明确的保存方式。** 自动保存本地草稿，Ctrl+S 主动写回原文件；关闭时确认，检测外部修改后拒绝覆盖。
- **细节与安装脚本完善。** 统一独立窗口圆角，修正安装器进程检测状态保护，更新产品截图和使用说明。

## 开始使用

安装后双击托盘图标打开面板。需要全局快捷键时，点击工作台侧栏「检查与配置快捷键」主动开启。升级会保留原有键位配置，新策略首次使用需要开启。

右键 Markdown 文件 →「打开方式」选择随序，可按需设为默认。支持 UTF-8、800 KB 内、20 万字符内的文本。

## 使用前了解

- 全选通常为 Ctrl+A。Alt+字母可能与其他应用菜单重叠；系统无法统一检测所有内部快捷键。
- 当前面向 Windows 11 x64，安装包尚无发行者数字签名。
- 本环境的回归、安装与覆盖升级已通过；此前安装卡顿的完整根因仍未确认，其他电脑的兼容情况需要继续验证。
