## 随序 0.2.28 · 更快的面板与独立文字工具

- 任务匣空状态移到右侧内容区中间；移除所有窗口的像素伙伴和相关设置。悬浮板三点菜单去掉圆形边框，保留入口与键盘操作。
- 悬浮板使用原生即时前台快照记录返回目标，避免等待前台助手的启动与排队。键位在后台保持就绪，收起后准备下一次显示，取消一分钟闲置后反复销毁重建。
- 关闭面板窗口的 Windows 显示／隐藏过渡，处理先出现薄框残影的问题；失焦立即收起，并使用现有鼠标边沿检测补足外部点击收起。
- 最近文档新增“清理记录”。只清理最近列表，不删除文章；“全部文档”仍可访问原有内容。
- 翻译和文本转换改为独立窗口，不再跳到内容库。可编辑原文、读取剪贴板或从最近图片提字，比较处理结果后复制或粘回原处。
- 翻译支持语言切换、原译文交换、Ctrl+Enter 重译与直达服务设置；迟到结果不会覆盖新内容，复制后保留窗口。使用已配置的翻译服务。
- 文本转换提供中文空格清理、紧凑段落、合并段内换行、空白清理与大小写转换；保留原文。内容库文字预览收紧行距，新增“紧凑复制”，清理后复制并保留原始记录。
- 速记采用与工作台一致的浅色顶栏、白色正文、图标按钮和状态栏，移除整块正文的蓝色焦点边框。

在悬浮板三点菜单中选择“检查更新”，下载并校验后，保存草稿并重启更新。
