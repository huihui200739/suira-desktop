## 随序 0.2.34 · 层级、阴影与控件反馈

- **玻璃层次更清楚。** 底层更透，键帽提亮，Iris 选中态与控件面分开；深浅主题均通过明亮、暗色和杂乱背景的原生合成截图检查。
- **内容有轻重。** 任务匣、剪贴板、工具箱、翻译结果和日历侧栏增加统一卡片阴影，深色模式降低高光。
- **统一玻璃下拉菜单。** 支持方向键、Enter、Esc、Home、End 和首字母跳转；原有选项值、表单与事件行为保留，复选框统一 Iris 勾选样式。
- **反馈更直接。** 面板以 160ms 轻缩放淡入，按键下沉、结果上滑和复制对勾提供轻量反馈；操作可立即响应，所有窗口遵循系统减少动态效果设置。
- 页面间距收敛到共享尺度，更新深浅主题与设置菜单截图。

在面板三点菜单选择 **检查更新 → 下载更新 → 保存草稿并重启更新**。更新保留本机内容、键位与设置。
