## 随序 0.2.43 · 更快、更省内存

这一版不改变操作方式，集中优化长时间使用时的响应与内存占用。

- 长文本处理修掉 O(n²) 字符串累加：4 万行合并从秒级降到约 8ms；剪贴板去重不再对整库排序，复制同一段文字直接命中；内容库搜索把一帧内的多次重建合并为一次。
- 截图标注把已提交内容缓存到按需分配的离屏画布，拖拽帧只重绘进行中的那一笔；马赛克颜色、放大镜主题色不再每帧重复计算；视口尺寸未变时跳过整屏重绘。
- 完成截图、文字识别、查看原图用的临时合成画布在编码后立即归还显存，关闭「查看原图」清掉整张 PNG 与解码位图；应用图标内存缓存加 LRU 上界。
- 剪贴板后台轮询先比对图片轻量指纹，内容没变时不再每 550ms 分配一整块 PNG 字节；保存数据文件去掉整库缩进，缩小写盘体积。
- 补充大文本合并、标注历史层、缓存上界等回归断言；覆盖层 116 项验收、全套 `npm test`、玻璃性能 / 延迟 / 启动检查均通过。

在面板三点菜单选择 **检查更新 → 下载更新 → 保存草稿并重启更新**。保留本机内容、组合动作、键位与设置。
