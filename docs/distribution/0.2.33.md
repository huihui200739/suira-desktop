## 随序 0.2.33 · 色彩、字体、图标打底

- **Iris 强调色。** 深浅主题使用统一十二阶，主按钮、选中态与焦点环保持一致；工作台继续使用石墨导航栏。
- **原版 MiSans。** 主工作台内置小米 MiSans VF，正文、强调和标题字重统一，数字采用等宽数字。为控制内存，面板与其他工具窗保留系统字体。
- **统一图标。** 钉图工具栏、日历翻月、Markdown 菜单箭头及工作台导航使用 Fluent 线性图标；彩色工具图标按类别配色，统一左上光源和 145° 渐变。
- 组件颜色集中到语义变量，增加自动检查，覆盖玻璃窗口、截图、Markdown 和导出页。
- 设置“关于”提供 MiSans 署名与原版协议。安装包中的字体和协议已与官方原版逐字节校验 SHA256。

在面板三点菜单选择 **检查更新 → 下载更新 → 保存草稿并重启更新**。更新保留本机内容、键位与设置。
