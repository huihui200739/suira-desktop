## 随序 0.2.38 · 面板认出手上的内容

- 面板顶部显示最近 60 秒复制或截图的内容，并附上下一步动作。到期自动隐藏，也可在设置关闭。普通面板与全屏键位随卡片自动适配。
- 划词默认关闭。在设置开启后，选中英文、唤起面板、按 T 即可填入翻译；结果就绪后按 Enter 替换原选区，Shift+Enter 换行。
- 读取前保存剪贴板全部可读取格式，发送 Ctrl+C，最多等待 250ms 后还原。临时复制不进入随序历史；管理员窗口或无法复制时安静放弃。
- 终端与密码管理器默认跳过，应用名单可修改。设置里明确说明 Ctrl+C 的行为及外部剪贴板历史、云同步和延迟复制风险。
- 记事本与 Word 的原位替换已实测通过；浏览器和 VS Code 桌面实测因控制工具阻断尚未完成。

在面板三点菜单选择 **检查更新 → 下载更新 → 保存草稿并重启更新**。更新保留本机内容、键位与设置。
