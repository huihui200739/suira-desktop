## 随序 0.2.32 · 截图翻译一步完成

- **看到英文，按 Alt+B。** 框选后自动识别并翻译；也可在面板按 B，或在截图工具栏点击“翻译” / 按 Y。
- **原文、译文一起看。** 大选区并排、小选区上下显示，支持复制原文、复制译文、加入任务匣和查看原图。点击“粘回原处”，可将译文直接写入截图前的编辑窗口。
- **中英文自动切换。** 英文默认译成中文，中文默认译成英文。翻译服务未配置时可直接前往设置，原文仍可复制。
- 翻译窗口新增“截图提字”，识别完自动返回并翻译；“最近图片提字”保留在原文栏的“…”菜单。
- 仅迁移仍使用出厂标注绑定的 B 键，保留自定义键位；标注仍可在动作列表中绑定。
- 工作台更新为石墨导航与冰蓝选中态，任务列表和正文衔接更自然；速记采用横线便笺和保存状态圆点。
- 修复原生窗口定位及译文粘回流程，统一语言判断，避免英文识别结果中的零星汉字干扰翻译方向。

在悬浮板三点菜单选择 **检查更新 → 下载更新 → 保存草稿并重启更新**。更新保留本机内容、键位与设置。

截图翻译需先配置翻译服务；使用 Alt+B 前需在设置中开启全局快捷键。
