## 随序 0.2.49 · 语音快捷键、设置与 Markdown

- 修复语音输入绑定 Alt+H 后仍触发钉图的问题。该键位交给语音输入时，原占用者钉图显隐移至 Alt+F8。浮板搜索框聚焦时也能响应已绑定的 Alt+H。
- 语音输入有独立设置页。翻译操作回到翻译卡片，修复缩放或窄窗口导致的模型选择、按钮和说明重叠。
- 参考妙言的编辑布局和源码高亮。打开文档后左侧仍可搜索并切换文档，目录可单独展开，源码为连续纸面，标题、链接、引用、列表和代码可直接区分。
- 修复 Markdown 源码滚动时斜杠菜单意外消失的问题。

在软件更新窗口选择 **检查更新 → 下载更新 → 保存草稿并重启更新**。
