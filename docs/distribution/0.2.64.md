## 截图可以截到随序自己的窗口了

- 随手面板的居中搜索框去掉了多余的焦点内圈，「⋯」和「动作／应用／工具箱」按钮更柔和；仍可按住顶部空白处自由拖动、用快捷键快速唤出，打开已运行的应用时也会优先切回已有窗口。
- 普通截图和长截图都能截到随序主窗口、速记、Markdown、日历、剪贴板条和浮引岛；用全局快捷键截图时，随手面板也会留在画面里。
- 速记的侧栏从顶到底，可折叠，笔记用五种颜色区分，状态移到右下角；速记和 Markdown 展开或收起侧栏时，侧栏控件留在原位，正文平滑滑动。
- Markdown 去掉了左上角重复的文件夹图标，导入单个文件的入口移到侧栏底部。
- 各处「⋯」里的「下一步」菜单更简洁：速记不用再点两层，操作成功或失败都有提示，菜单关了也能看到错误；剪贴板条的菜单更轻巧，动作多时也能滚动找到要用的一项。

在随手面板搜索框右侧的「⋯」菜单选择「检查更新」，也可下载本页的 Windows x64 安装包。
