## 随序 0.2.48 · Markdown、截图与语音输入

- Markdown 编辑器移植了妙言（MiaoYan）的部分编辑行为，包括括号配对、列表续写和缩进。保留了上游 MIT 许可证。
- 调整贴图工具栏和菜单的尺寸与对齐，覆盖 100%、125% 和 150% Windows 显示缩放。
- 关闭窗口回到托盘后，释放闲置的窗口资源，降低后台内存占用。
- 修复按住型快捷键的录入与触发、区域截图取消后再次唤起，以及停用快捷键后浮板入口的同步。
- 修复语音输入的快捷键与浮板入口。实际转写取决于所配置的服务是否支持音频转写接口。

在软件更新窗口选择 **检查更新 → 下载更新 → 保存草稿并重启更新**。覆盖更新保留本机内容、键位和设置。安装包尚未代码签名。
