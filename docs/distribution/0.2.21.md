## 随序 0.2.21 · 圆角修复与软件内更新

- 修复悬浮板、日历、Markdown、剪贴板等窗口圆角外露出的灰色尖角。
- 圆角窗口改用稳定的半透玻璃，保留彩色工具图标、即时轻抬、倾斜和单次反光；桌面文字的原生模糊暂不启用，避免系统背板越过圆角。

### 从软件内更新

随手面板搜索栏右侧三点 → **检查更新** → **下载更新** → **保存草稿并重启更新**。下载完成后自动校验；重启前保存随序草稿。请从普通 Windows 桌面启动已安装的随序；受限启动的安装器会在修改文件前停止。

本次公开源只提供安装包、blockmap、更新元数据与 SHA256SUMS，不包含用户数据或私有源码。安装包尚未代码签名，Windows 可能显示安全提示。
