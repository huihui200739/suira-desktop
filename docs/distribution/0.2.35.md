## 随序 0.2.35 · 逐个界面改版

- **面板更安静。** 空键使用淡底细线，名称加深，字母角标在悬停或键盘聚焦时显示；设置可开启紧凑面板，只显示已绑定的键。默认搜索提示改为“搜索工具、应用、内容”。
- **任务内容少些干扰。** 操作按钮在悬停或聚焦时出现，快捷键检查入口收进设置。
- **处理轨迹贴着内容。** 移除独立导航入口，在每条内容详情中展开原文、结果、错误与重试；耗时默认隐藏，按需查看。
- **文字工具合成一窗。** 翻译与文本转换通过标签切换，语言选择收成一行胶囊；停止输入 0.5 秒后自动翻译，支持中文输入法组词与旧结果保护。结果可继续翻译或转换，也能返回上一步。
- 日历选中日期只保留底色，时钟不再显示秒。
- Markdown 顶栏精简为搜索、最近、模式、保存和更多；文件操作、导出和删除移入更多菜单，删除仍需确认。
- 剪贴板卡片移除重复标题，为正文增加空间，角上显示来源应用图标。
- 工具箱网格居中，并按窗口宽度调整列数。

在面板三点菜单选择 **检查更新 → 下载更新 → 保存草稿并重启更新**。更新保留本机内容、键位与设置。
