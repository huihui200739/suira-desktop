## 随序 0.2.29 · 更清楚的收集与阅读

- 移除悬浮板右下角的剪贴板、截图快捷入口；原有键位、工具箱入口和全局快捷键仍可使用。
- 修复 Windows 缩放下点击三点菜单导致面板收起的问题。外部点击使用与窗口一致的 DIP 坐标，正常失焦仍会收起。
- 重排任务匣：任务标题与新建入口收进列表栏，状态筛选采用紧凑标签；右侧以有固定阅读宽度的内容面展示任务，减少重复标题与横向空白。所有任务和内容操作保留。
- OCR 自动整理汉字间的多余空格与空行，保留分行、英文单词与链接。识别框使用正常字距和更紧凑的行高。
- 内容库卡片、任务内容和全文预览统一紧凑排版；旧记录也即时生效。展示整理不覆盖原始记录，“复制原文”和“紧凑复制”保持区分。

在悬浮板三点菜单选择“检查更新”，下载校验后保存草稿并重启更新。
