## 随序 0.2.37 · 统一的“下一步”接力条

- 截图识别、文字工具结果、剪贴板条、钉图菜单与速记菜单共用下一步动作。常用三个动作直接显示，其余放进“…”；支持 1–9 和 Ctrl+K 完整列表，输入文字时数字键继续用于输入。
- 文字可追加到最近速记、当前 Markdown 文档，或钉在桌面。没有打开的文档时，追加到当天的“今天”文档；追加前保留目标窗口尚未保存的编辑。
- 识别“明天下午3点”“11月8日 14:30”“下周五”等日期，先打开可编辑日程草稿，明确保存后才加入日历。速记识别到日期时，底栏显示“加到日历？”。
- Markdown 斜杠菜单新增“截图”和“截图文字”，框选完成后插到光标位置。支持源码与可视化编辑；取消截图保持原文，插入的截图作为文档附件保留。
- 文字钉图支持原样显示、选择文字、复制和另存为；图片条目优先显示提字，英文条目优先显示翻译。

在面板三点菜单选择 **检查更新 → 下载更新 → 保存草稿并重启更新**。更新保留本机内容、键位与设置。
