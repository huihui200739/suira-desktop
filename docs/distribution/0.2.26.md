## 随序 0.2.26 · 沉浸写作与浅色工作台

- Markdown 新增可视化写作模式，支持选中文字的浮动工具栏、右键编辑菜单和 `/` 快速插入；可设置标题、粗体、斜体、下划线、删除线、文字颜色、高亮与字号，插入列表、待办、引用、代码块、表格、链接及图片引用。
- 打开文章后，左侧显示当前文档目录，支持分节折叠、点击定位和整体收起。最近文档移至顶部“最近”入口。
- 写作区铺满连续的白色阅读底色，消除正文四周的玻璃边；深色主题使用对应的不透明阅读面。保留 Markdown 源码、左右预览、独立阅读与原文件保存。
- 工作台改为统一的浅色背景、磨砂侧栏与清楚的内容面，重排任务、设置和操作层次，移除顶部快捷键提示；悬浮板柔光键帽与日历材质沿用。
- 颜色、高亮、字号以 Markdown 内嵌的安全样式保存，重开与 HTML 导出保留。包含 YAML 元数据、注释或未支持 HTML 等扩展语法的文章使用完整源码模式，避免编辑时丢失原始内容。

在三点菜单中“检查更新”，下载校验后，保存内容并重启更新。原有数据、密钥、自定义键位和伙伴设置沿用。安装包未代码签名。

工作台设计参考 [Impeccable](https://github.com/pbakaus/impeccable) 的布局、层级与一致性方法；写作交互参考[飞书官方文档](https://www.feishu.cn/hc/zh-CN/articles/299406656534-%E5%9C%A8%E6%96%87%E6%A1%A3%E4%B8%AD%E8%AE%BE%E7%BD%AE%E6%96%87%E6%9C%AC%E6%A0%B7%E5%BC%8F)。
