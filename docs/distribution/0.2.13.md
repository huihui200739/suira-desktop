## 随序 0.2.13 · 在线更新现已接通

这是公开更新源的首个版本，适用于 Windows 11 x64。

### 后续更新，在软件内完成

点击随手面板搜索栏右侧三点 → **检查更新**，查看新版本、下载并校验，再选择 **保存草稿并重启更新**。源码仓库保持私有，安装包与更新说明从独立公开仓库分发。

旧版首次接入需要手动安装本版本一次。覆盖安装前请先保存文档，并从托盘右键退出随序。后续正式版本可以在软件内更新；当前版本检查更新时会显示已是最新版本。

### 键位面板，也能沉浸全屏

- 全屏保留原有 38 键布局，按可用空间等比例放大。
- 应用启动台与键位布局各自保持，不因进入全屏而跳到另一种布局。
- `Alt+S` 仍打开小型随手面板，保留日常使用习惯。
- 全屏图标与文字提亮，背景、键帽和功能图标层次更清楚。

### 更新时，先照顾好手头的内容

- Markdown 和速记先保存为随序草稿，保存失败会取消安装。
- 安装器等待旧进程正常退出，避免退出途中被误判为仍在运行。
- 更新保留本机内容、设置和键位，不更改 Markdown 默认打开方式。

安装包尚未代码签名，Windows 可能显示安全提示。`SHA256SUMS.txt` 可用于核对完整性。此处不提供便携版自动更新，也不会静默抢占被其他软件使用的全局快捷键。
