## 截图、写作和日程都更顺手

- 截图可以吸附到窗口，标注后可给图片加边框和背景；钉图支持提取文字和鼠标穿透。
- Markdown 可以直接浏览本地文件夹，粘贴的图片存到文档旁边，还能整理中英文间距、把文档当幻灯片播放。
- 剪贴板新增自定义分组和纯文本粘贴，颜色记录可以预览并复制为 HEX、RGB 或 HSL。
- 日历可在侧栏直接新建待办或倒数日，也可用滚轮或键盘翻月；随手面板的搜索结果支持 `Alt+1` 到 `Alt+9` 直达。
- 工作台和工具窗口更易读，随手面板保留玻璃效果，内置工具换上了新的图标。

在随手面板搜索栏右侧的「⋯」菜单选择「检查更新」，也可下载本页的 Windows x64 安装包。
