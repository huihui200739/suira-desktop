## 随序 0.2.31 · 按内容回看处理过程

- 处理轨迹按内容关系归组，同一份内容的提取文字、整理、翻译和复制串成一条处理链；同名但无关联的内容保持独立。
- 统计收紧为概览，加入带数量的状态筛选；支持搜索内容名称、动作和错误原因。
- 展开步骤查看原内容与处理结果，支持直接预览、重试失败步骤、调整翻译及打开服务设置。
- 同一步骤的多次尝试折叠在一起；后续成功后更新状态，保留之前的失败记录。原内容已清理时如实提示，禁止无效重试。
- 展示实际处理耗时和步骤用时；不计算用户操作间隔，不显示虚构费用。运行中更新计时，刷新后保留展开状态。
- 沿用灰白工作台、蓝色强调及深浅主题；未引入额外的 React 或付费 UI 依赖。

在悬浮板三点菜单选择“检查更新”，下载校验后保存草稿并重启更新。

信息组织参考 affectUI 的 [Agent Inbox](https://www.affectui.com/components/agent-inbox)、[Tool Call Card](https://www.affectui.com/components/tool-call-card) 与 [Trace Waterfall](https://www.affectui.com/components/trace-waterfall) 文档；界面与分组逻辑为随序独立实现。
