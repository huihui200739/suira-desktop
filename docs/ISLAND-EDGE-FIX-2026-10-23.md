# 顶部暂存：按用户截图修正实际显示

这轮针对截图里的常驻白色胶囊，以及带白色外圈、厚阴影的大卡片。上轮仅验证了独立实例，未把用户桌面运行的实例切换到新代码；这轮直接检查并更新实际实例。

## 交互与外观

| 场景 | 当前行为 |
|---|---|
| 平时、普通悬停、拖动文字 | 原生窗口隐藏，不显示胶囊、提示线或空卡片 |
| 文件进入顶部中央 | 出现 440×108 DIP 紧凑接收区 |
| 暂存已有文件，或主动从托盘打开 | 520×148 DIP 文件托盘 |
| 文件拖离、Esc、使用完离开 | 隐藏窗口，恢复鼠标穿透 |
| 旧版请求 `rail` | 直接隐藏，不能重新显示胶囊 |

托盘顶边贴屏幕工作区上沿，四周不留 12px 阴影边。取消白色底板、大虚线空框和白色嵌套卡片，使用低反差烟灰半透明材质。Windows 支持时调用[原生背景材质](https://www.electronjs.org/docs/latest/api/browser-window#winsetbackgroundmaterialmaterial-windows)，并用原生窗口形状裁切底部圆角，避免材质铺成外围矩形；不支持时保留半透明外观。

增加托盘菜单“重启并应用更新”。后台启动不主动弹出主窗口，已有数据目录保持不变。

## 验证

- 页面渲染与交互：105 项通过；原生热区/形状/宿主：8 组通过。
- 全量 `npm test` 通过；新增重启入口的 preload/IPC/托盘接线检查通过。
- 当前实际用户实例的 UI 版本为 `edge-shelf-20261023.2`。
- 读到空闲 `mode=sleep`、`windowVisible=false`、DOM `sleep`，原生拖动侦测 ready。
- 实际实例展开接收区为 440×108、`y=screen.availTop`，内容 rect 从 `(0,0)` 铺满，阴影为 `none`，顶部为直边、底部为 16 DIP 圆角。
- 在真实实例派发临时 Files 事件验证：普通悬停隐藏、文字拖拽隐藏、文件进入显示、文件离开隐藏。仅测试 enter/leave，不修改暂存内容，不创建用户文件。

真实 Windows 资源管理器到第三方应用的完整 OLE 拖放，仍与页面事件验证分开；这里不把临时测试事件称作手工跨应用拖放验收。
