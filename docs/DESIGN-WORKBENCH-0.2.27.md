# 收集工作台与多模式文档

工作台的使用场景是收集和整理；文档的使用场景是长时间编辑、阅读。方向沿用随序的蓝色主操作、浅色导航与彩色工具资产，桌面悬浮板保留原生玻璃。工作台和正文使用不透明底色。

本轮审视：原工作台把两条任务和大面积空白装进圆角卡片，五个低频按钮与主操作同重；编辑工具条随模式变化，斜杠只在可视化编辑器工作；悬浮板在显示后重置模式、重复加载并重设原生材质，首帧可能是未完成或过期的内容。

布局按导航、任务索引、当前内容展开。192px 导航与 264px 索引支持稳定定位，右侧内容直接铺在白色工作面；1200px 以下操作换行，900px 以下任务索引移到内容上方并限制高度。任务搜索与状态筛选使用真实任务数据，创建任务后重置筛选以显示新任务。低频操作使用顶层 popover，避免容器裁切。

Markdown 菜单定义由两种编辑器共用。可视化模式使用 Tiptap 事务；源码、分栏的操作仅修改选区或所在行，沿用 textarea 撤销记录，避免重新序列化扩展语法。预览打开菜单不会改文档，选择命令后才进入编辑。文字颜色、高亮、字号继续使用允许的内嵌样式，经过既有安全过滤与导出流程。

显示链路先记录返回目标，再等待载入、隐藏状态下的渲染准备通知，最后显示和聚焦。每个请求携带版本号，收起与销毁使旧请求失效。窗口原生材质按句柄和状态缓存，每次原生显示前刷新一次以消除 Windows 跨隐藏周期的旧背景缓存；移除 show/focus 后的失效及 80ms 二次重设。隐藏时保留绘制，内容两帧布局后确认；不使用桌面截图或静态壁纸。

验证使用隔离资料、虚构文档和空剪贴板，未读取用户文档或发布用户录屏。证据见 document-editor-0.2.27.json、document-modes-0.2.27.json 与 panel-reveal-0.2.27.json；原生显示检查覆盖首次、重复、销毁重建与准备期间取消，显示事件采样有完整 38 键及准备标记。native-glass-0.2.27.json 额外记录真实 DWM 合成的动态红蓝背景透出、条纹模糊与四角透明像素检查。验证不代表所有显卡驱动的无闪屏保证。
