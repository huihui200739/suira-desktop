# 0.2.20 彩色工具物件与即时键位反馈

日期：2026-11-02。依据用户确认的方案及参考截图，补齐上一轮保守配色、反馈迟缓和跨页面不统一的问题。

方向：随序是通过键位调出截图、内容和日程工具的桌面工作台；性格轻巧、灵敏、有玩心；材质来自磨砂托盘和有体积的工具物件；丰富度集中在工具图标和当前悬停键；固定键位字母是共同识别细节。

| 要求 | 实现 |
| --- | --- |
| 图标鲜艳但面板安静 | 14 个动作键、15 项工具箱共用五组物件色，保留中性界面与第三方应用原图标；主体、侧面、上缘高光和接触阴影共用光源 |
| 日历和回到桌面重做 | 大面积珊瑚红日历配小奶油日期页；紫色窗口扇面表现回到桌面 |
| 更灵敏的 3D 反馈 | 进入立即轻抬 1px；停留 40ms 后抬升约 2.8px、倾斜上限 2°；离开快速回落，扫过保留 60ms 微弱回落轨迹 |
| 彩色光泽 | 当前功能键内一次 180ms 反光，280ms 重入冷却；静止不循环；不在背景、外边框上扩散光晕 |
| 正确的操作状态 | 点击约 75ms，名称和命中区域固定；拖拽、失焦、页面隐藏、尺寸变化和减少动态效果会清理反馈 |
| 键帽和布局层次 | 空键降低底色和边缘强度，功能键保留乳白半透；常规行距 20px，小窗口 10px；品牌区缩小，搜索居中 |
| 第三张图中跨页面部分 | Markdown 首页/顶栏、日历顶栏/空状态、剪贴板顶栏/空状态/文件与链接占位共用图标；文档、图片和日程内容维持稳定底色 |

## 验证

- 完整 npm test 通过，覆盖原有功能和新增键帽、按压、拖拽、减少动态效果、工具箱检查。
- 实际鼠标以 250、700、1400px/s 扫过全部四行 38 键，每一键均观测到可见位移。各速度最大首次可见延迟为 32.3、17.9、17.4ms。这是当前机器与测试环境的采样结果，不是所有机器的延迟保证。
- 单次反光、重入限频、固定名称与每帧零布局读取通过。进入时缓存一次命中框和样式；随后的指针帧只写变换。记录见 [motion JSON](keycap-motion-verification.json)。
- 真实 Electron 的 workspace、launcher 和 screenshots 检查通过；包含编辑保存、日历操作、菜单、全屏、重启记忆、圆角、缩放和最大化恢复。需要焦点的检查串行执行。
- 修复两项视觉回归：旧空状态规则污染物件层，日历的 page 类名命中隐藏页面规则。截图及打包检查均针对这两项增加核验。
- 安装器普通/低完整性启动、数据保留、文件占用回滚检查通过；安装包 CRC、100 个源码文件、更新元数据和 SHA512 一致。见 [release](release-0.2.20.json)。

## 验证边界

本轮原生屏幕采样读取到资源管理器背景，受控红蓝背景本身也未被采到，故不能重测桌面透色或条纹模糊强度；未将这次失败算为通过，也未调整通过阈值。工具现在先检查受控背景可见性，避免把采集会话问题误报成材质退化。历史 0.2.17 模糊量化保留原版本标识。本轮仍需由安装版隔离配置确认四个窗口的原生模块与设置切换。

直接启动工作区打包目录的 Electron 受本机会话限制，调试端口未就绪；没有把该尝试算作通过。最终安装版本和数据核验另行补记。

设计审查方法参考 Damir Sokolovsky（@heydamir）的 [unslop](https://github.com/heydamir/unslop)，CC BY 4.0。图标是本项目代码绘制的共享物件。

清理已运行 npm run clean -- -IncludeObsoletePackages：移除 22 项、约 867.6 MB 闲置测试缓存、旧安装包及重复构建。保留桌面当前安装包、实际运行程序、依赖和加密配置快照；此前被审批拒绝删除的旧程序副本未再尝试删除。
