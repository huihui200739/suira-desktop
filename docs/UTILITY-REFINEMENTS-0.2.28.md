# 0.2.28 问题修复与验证

保持既有柔光键帽、彩色工具物件和实时背景玻璃。工作台、文档正文、速记与文字工具以白色内容面和安静的浅色顶栏组织长时间阅读；保留一个蓝色操作色。任务空状态居中在右侧内容区，三点入口移除圆形描边，像素角色与设置不再加载。

旧面板把前台助手查询、状态重载、字体等待和两帧排版串在每次唤起之前，并在一分钟后销毁高频窗口。现在用 Win32 只读快照同步记录 HWND、PID 与进程创建时间，返回粘贴时仍使用既有安全校验。辅助查询仅作为 100ms 有界回退；回退超时不借用旧目标。面板在隐藏时准备，下次直接显示。DWM 的 TRANSITIONS_FORCEDISABLED 设置到面板 HWND，移除系统的显示与隐藏过渡，保留原生背景与圆角。失焦处理不再被 350ms 布局标记拦住；鼠标按下边沿在真实屏幕坐标换算为 DIP 后补充外部点击关闭，拖动途经外部不会当成新点击。

最近记录通过文章元数据标记隐藏，文章、原文件和密钥不删除；全部文档列表提供继续访问入口，重新打开后恢复到最近列表。速记保持原有自动保存、置顶和关闭流程，修改材质和图标表达。

翻译和转换共用独立文字工具，原文与结果并排，操作名称与实际效果一致。默认读取当前剪贴板，显式操作支持最近图片提字。网络翻译沿用用户已配置的服务，输入修改和新请求使旧结果失效；错误显示在窗口内。复制不会关闭编辑内容。“紧凑复制”是明确的派生操作，清理 CJK 间空格与重复空行，原始捕获不覆写；普通复制标为复制原文。转换只在选择复制／粘贴时保存派生结果。
