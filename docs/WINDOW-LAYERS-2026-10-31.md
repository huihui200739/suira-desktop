# 0.2.5 窗口层次与任务栏修正

> 后续更正：0.2.5 的位置适配在分数 DPI 下会触发窗口尺寸持续增长。此前测试遗漏了连续回写与关闭重开；请升级 0.2.6，见 [修复与验证记录](SHARED-FEATURES-2026-10-31.md)。本页保留当时的实现与验收范围，不作为已彻底修复的承诺。

保留原有浅色玻璃外观及布局，解决独立日历、Markdown 与工作台重叠时边界难辨，以及白色窗口让透明任务栏图标失去对比的问题。

## 行为

- 当前窗口显示清晰细描边，后台窗口降低标题区强调；标题处显示当前/后台提示。
- 日历与 Markdown 使用各自的类型图标及现有蓝色/紫色系的轻微标题栏色调，文档长标题显示省略号。
- 正常移动结束后将窗口留在该显示器工作区内；修改尺寸、恢复位置和显示器变化时重新约束。
- 拖动中仍可跨显示器移动。原生窗口可见区域排除各显示器任务栏；最大化额外裁去 Windows 隐藏边框超出的区域。
- 普通窗口保留少量边界余量，避免 150% 等分数 DPI 下取整向外多出一像素。未开启原生亚克力，不重引入四角灰色矩形。
- 全局模式下增加显式重新注册入口；已释放的按键可重试，仍被占用的按键提示换键，不强制接管。

透明任务栏可能透出它后方窗口的内容。玻璃视觉不等同于完全透明，更不保证白色任务栏图标在白色内容后方仍有对比；本次通过工作区约束和原生可见区域隔离处理。

## 验证

- `tests/test-window-resize.js`：上下左右任务栏、负坐标副屏、超大窗口、分数 DPI 余量、跨屏区域并集和空裁剪安全性。
- `npm run test:surfaces`：真实窗口位置与焦点样式；DPI 感知的原生 HRGN 检查，确认最大化可见区域不覆盖任务栏，并复核缩放、恢复与各窗口圆角。
- `npm run verify:release`：真实热键冲突与释放后重试；Markdown 打开、保存及原有面板键盘操作回归。
- `npm run verify:workspace`、`npm test`：工作流及完整自动化回归。

打包源码比对、安装包 CRC 和实际打包程序启动检查由发布工具验证。最终产物见 [0.2.5 清单](release-0.2.5.json)。

这些检查覆盖当前 Windows 11 x64、150% 显示缩放，以及几何单元测试中的多屏情况；未声称在所有第三方任务栏工具和多屏组合中完成实机验证。未修改系统任务栏设置、用户数据或当前安装。
