## 背景：为什么之前启动不了

排查结论（已实测确认）：

1. **`ELECTRON_RUN_AS_NODE=1`** —— 让 Electron 以 Node 模式启动，`require('electron')`
   返回路径字符串，`app` 为 `undefined`，第一行 `app.setName()` 就崩。
   新版已给出中文提示。启动前清掉：`Remove-Item Env:\ELECTRON_RUN_AS_NODE`
2. **工作区目录的沙箱 ACL** —— 项目目录上有 `Everyone: Deny DeleteSubdirectoriesAndFiles`
   拒绝项。Electron 初始化时触发断点异常，退出码 `0x80000003`（STATUS_BREAKPOINT）。
   实测：**同一个 exe 放到工作区外（如 `C:\temp\el45\`）就能正常启动**。

所以在本机验证时，用工作区外的 Electron 加载项目页面：

```powershell
C:\temp\el45\electron.exe . --remote-debugging-port=9223
```

或用封装好的脚本：`node tools/electron-real-check.js`

### 环境自检

`npm run diag` 会生成一份环境报告，落在 `%APPDATA%\随序 SUIRA\diag-report.txt`，
包含窗口尺寸、快捷键注册状态、显示器与缩放、OCR 引擎、剪贴板监听、托盘与全部设置。
排查问题时先看这份报告，比逐项试错快。自检只读，不改设置也不动数据。

## 反馈什么

最省事：**报编号 + 一两句现象**，比如「3 不对，松手后要手动点识」。

如果窗口起不来，把下面输出发我：

```powershell
C:\temp\el45\electron.exe . --remote-debugging-port=9223
echo "退出码: $LASTEXITCODE"
```
