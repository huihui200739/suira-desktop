# 当前窗口粘贴与滚动长截图

## 剪贴板粘贴

底部历史条的按钮改为“粘贴到当前窗口”。每次唤出历史条时，独立记录当时正在使用的窗口；历史内容来自哪个应用不参与选择目标，也不复用上次主窗口的返回记录。

从悬浮面板进入历史条时，只交接本次面板唤起时的目标。提交时如果实际前台已经变成另一个外部窗口，使用当前窗口；历史条自己获得焦点时，使用本次记录。记录失效或无法验证时只复制，不把内容发到旧窗口。

点击卡片或按 Enter：先写入选中的文字/图片，立即收起，再验证窗口实例和焦点并粘贴；系统剪贴板保留该项，后续 Ctrl+V 仍使用选中的历史内容。缺失的历史图片显示错误，不再降级成粘贴文件路径。

## 长截图的用法

1. 悬浮面板默认 `G`、工具箱“长截图”或搜索“长截图”。普通截图完成框选后，也可点工具栏的长截图图标或按 `G`。
2. 框选同一块屏幕中的滚动内容，尽量避开滚动条、悬浮按钮和动态视频。
3. 在原页面向下滚动，稍停后自动拼接。不要一次滚过整个选区高度，要保留一部分重叠内容。
4. 可暂停/继续；点击“完成并预览”生成 PNG 并进入改图窗口，继续标注、复制或另存为。取消不新增图片。

## 实现与范围

- Windows 原生区域采集组件保持单进程，按需返回无损 PNG；通过逻辑坐标到物理坐标转换处理 DPI，不对采集帧重采样。
- 比较连续帧，画面停稳后再匹配；使用覆盖重叠区的多行像素特征搜索滚动距离，固定页眉/页脚只保留一次。
- 重复画面不追加，反向滚动不追加；重叠不足、横向移动、无法消除歧义或尺寸变化时暂停并提示，保留已经拼好的部分。
- 切换窗口/标签页、移动或缩放目标窗口后暂停。恢复原页面与位置后可继续，或完成已有部分后重新框选。
- 工具条优先放在选区外；空间不足时在采集瞬间隐藏并等待桌面合成刷新，避免把工具条拼进去。
- 当前为手动向下滚动的长截图，不会替用户自动滚动。单屏选区至少 120×160 DIP；输出最高 16384 像素、总像素不超过 4000 万、最多 120 段，PNG 上限 64 MB。
- 动态/受保护内容、改变布局的虚拟列表及没有可辨认重叠的重复页面，可能需要减小滚动距离或重新框选。无法对齐时不给出猜测结果。

坐标转换依据 [Electron screen API](https://www.electronjs.org/docs/latest/api/screen)；区域复制与合成刷新分别使用 [BitBlt](https://learn.microsoft.com/en-us/windows/win32/api/wingdi/nf-wingdi-bitblt) 和 [DwmFlush](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/nf-dwmapi-dwmflush)。

## 验证

- `npm run test:long-capture`：精确位移、固定栏、反向/重复/歧义/横向画面、尺寸上限、停稳采集、切窗/移窗/换页暂停、取消和区域协议清理。
- `node test-clipboard-session.js`：本次窗口、面板交接、切换聊天与过期会话不复用旧目标。
- `npm run verify:long-capture`：真实 Windows 组件编译和连续区域 PNG 协议；独立 Electron 数据目录中的真实 preload / IPC / UI、浏览器排版与滚动采集帧、三段拼接逐行像素校验、完成入库预览及取消后停止采集。
- IPC 验证中替换前台窗口探针和系统剪贴板/粘贴适配器，使用两个模拟聊天目标与本地生成页面；不向用户的聊天发送测试内容，也不把用户画面写入文档。
