# 工作台、日历与 Markdown

## 本次变化

- 移除壁纸规划入口，W 回到未绑定状态；F 日历、M Markdown 可从键盘、Alt 全局组合键和工具箱打开。
- 日历：周一开始的月视图、回到今天、日期选择、全天或指定时间日程、备注、编辑、完成与删除。
- Markdown：文档列表与搜索、分栏编辑预览、标题与格式工具、400ms 自动保存、Ctrl+S、文件导入导出、删除。标题和正文复用内容库的加密与落盘，固定保存，不受剪贴板保留期影响。
- Markdown 使用本地打包的 Marked 与 DOMPurify（依赖锁文件及浏览器资源、许可证均入库，安装和构建时同步资源）。预览清理脚本、表单、事件属性和危险链接；任务复选框只读。图片暂不在预览中加载，http(s) 链接点击后交给系统浏览器。
- 任务匣新增完成/重新打开、重命名，剪贴板内容优先加入当前选中的任务；处理轨迹支持状态筛选与错误搜索。
- 设置改为通用、翻译、快捷键、数据隐私、关于五类，保留原控制器。
- 搜索按钮参考 [Bencho Expanding Search](https://bencho.dev/blocks/seek) 的形态变化，使用原生 CSS/JS 实现。入口固定在品牌右侧，指针进入约 14px 邻近范围展开，移开收起；移除关闭叉号，保留输入内容、键盘导航与 F3 聚焦，遵循减少动画设置。未引入网站运行时或整套 React 组件。

## 快捷键与翻译

- 长截图增加独立快捷键设置，默认 Alt+G；面板换位、清除、改键、重启与冲突回滚共用现有配置事务。
- 全局动作不再因图片编辑器获得焦点而全部静默忽略。旧 captureBusy 没有对应工具窗口时会复原；已有采集窗口时重新显示它，避免丢掉现有会话。
- 系统占用时通过精确匹配的原生按键监听接管已配置组合，设置显示“兼容按键监听”；只发送配置项名称，不采集输入文字。保留系统保留键限制，监听助手失败仍显示真实原因。
- OpenAI 兼容根域名自动使用 `/v1/chat/completions`；已有版本路径和完整端点保持正确，不重复拼接。测试连接前统一保存配置，目标语言为英语时采用中文测试句。
- 没有使用用户的付费密钥做真实服务调用；服务商的实际可用模型仍以其账户为准。

## 验证

- `npm test` 完整回归。
- `node test-workspace.js`：根 URL、完整端点、自定义路径、日期边界、日程编辑完成、文档 CRUD、重载、保留策略、跨类型拒绝。
- `npm run verify:workspace`：独立 Electron 数据目录与空剪贴板。真实 IPC/落盘、日程与 Markdown UI、导入导出、任务状态、脚本清理、自动保存重载、搜索展开收起；用注入的系统注册器触发真实 Alt+G 回调，连续取消再开启框选。
- `npm run verify:panel-global`：全部内置快捷键、键位移动与占用回滚；动作副作用使用替身，避免实际锁屏等行为。
- `node tools/electron-long-native-check.js`：外部测试窗口的实际 GDI 采集、向上向下滚动、回访不增长、两种入口以及真实回车注册。
- 新便携包使用本机 Electron 45 构建。用户实际登录的翻译服务未做付费调用。`tools/portable-workspace-check.js` 另从独立数据目录直接运行桌面 EXE，使用 Windows 键盘事件验证 Alt+G 连续两次、Alt+F、Alt+M 与包内 Markdown 预览；当前电脑普通 Alt+G 注册返回 1409，兼容监听实际生效。
