# 0.2.6：先把共同功能打磨可靠

日期：2026-10-31。参考 [浮引官网](https://fg.vkr.me/) 与 [Mac 更新日志](https://fg.vkr.me/mac/changelog/)，重点核对近期及历史中与面板、剪贴板、日历、Markdown、图像工作流有关的条目。本报告依据公开产品说明与随序源码、测试进行对照，没有在 Mac 上安装竞品实测，也不把官网宣传当作实测性能结论。

## 共同功能对照

| 共同功能 | 公开资料呈现的重点 | 随序的差距与本轮处理 |
| --- | --- | --- |
| 窗口与高频交互 | 多屏、跟随与操作稳定性 | 0.2.5 出现尺寸反馈循环。本轮先修复并补充重复移动、闲置、重启和分数缩放验证。 |
| 剪贴板 | 内容辨识、预览与连续操作 | 原卡片层次偏白、长文字难确认。本轮加入渐变、类型底色、全文查看和独立复制，保留原有搜索、分类、收藏、图片编辑与粘贴。 |
| 日历 | 月份选择、手势与日期层次 | 本轮补上标题选年月、滚轮翻月与周末底色；保留日程、农历、倒数日和 ICS 导出。 |
| Markdown | 文档阅读、编辑与定位 | 本轮补充正文查找与匹配跳转。已有目录、分栏、文件保存和导出；源码着色、文档标签页与更强的所见即所得仍未补齐。 |
| 面板与应用 | 搜索、键位与整理衔接 | 已有拼音搜索和 38 键绑定。本轮回归原有交互；应用文件夹、批量整理等仍有差距，未宣称已经实现。 |
| 截图、识字、钉图与改图 | 工具间流转与查看细节 | 已有主流程。OCR 图文联动、精细查看和更多批量处理需要后续专项完善，本轮没有冒充功能全面追平。 |

上述概括是对公开资料的简要归纳。具体落地顺序是本项目根据真实缺陷与现有代码作出的判断，优先处理可靠性和少走一步的交互。没有照搬对方代码、图标或品牌，也没有扩展到当前不具备的遥控、语音及云同步等工具。

## 窗口回归的原因与修复

150% 显示缩放下已实际复现：反复读出窗口逻辑边界再写回，会让尺寸逐次增加。0.2.5 的边界适配放大了这个问题。Electron 45 的同类取整问题也有 [上游记录](https://github.com/electron/electron/issues/55245) 和尚在开发的 [修复提案](https://github.com/electron/electron/pull/55429)；本项目没有把未发布补丁当作已解决依赖。

- 位置纠正使用 Win32 的保留尺寸移动，不通过反复回写逻辑宽高实现移动。
- 原生组件仅允许调整随序自身窗口，不改变前台焦点或其他程序的窗口。
- 工作台状态额外记忆像素尺寸与对应缩放比例，恢复时进行一次精确校准。
- 保留原生任务栏区域裁剪与圆角，接受合理的像素取整余量，避免重新进入纠正循环。
- 增加明确的「恢复默认大小」，用户可恢复旧版本遗留的过大窗口，不清空内容或其他设置。

## 本轮体验调整

剪贴板使用静态蓝紫渐变，没有持续流动动画。空格或右键可查看选中记录，长文字保留完整内容；Ctrl+A 在预览内仅选中预览正文，Esc 返回，复制按钮和 Ctrl+C 不自动粘贴。原有 Enter 粘贴入口保留。预览只读取本机记录，不加载网页内容。

日历可点击月份标题选择年月；月历内一个连续滚轮手势只切换一次，Ctrl+滚轮不会被翻月拦截。Markdown 的 Ctrl+F 查找支持字面文本与大小写无关匹配，特殊符号不会被解释成正则表达式；查找本身不修改文档，已有自动保存和外部文件保护继续生效。

## 验证与交付范围

- 窗口稳定性：当前 Windows 11 x64、150% 原生缩放；通过运行参数补充 125% 与 175% 缩放验证。覆盖连续移到屏幕下沿、闲置、关闭后重开、原生组件及 PowerShell 后备路径、恢复默认尺寸。
- 剪贴板：原有回归及新增的全文预览、无自动粘贴、独立复制、预览选区、文本安全呈现、取消后迟到响应保护。
- 日历与 Markdown：真实 Electron 月份跳转、手势防连跳、正文查找、原有保存、重载、关闭和导出流程。
- 发布包：源码与本地原生组件逐文件比对、安装包归档 CRC、实际打包程序启动与超大窗口恢复检查。
- 安装器：以独立名称、独立路径的测试产品完成全新安装、覆盖升级与卸载；核对安装内容、含空格及中文路径、Markdown 打开方式注册，并确认现有默认打开方式未改变。

本轮未发布 GitHub Release；安装包与校验信息见 [0.2.6 产物清单](release-0.2.6.json)。实际多台显示器混合缩放、所有第三方任务栏工具、竞品 Mac 原生体验未作全面实机认证。
