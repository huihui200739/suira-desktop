# 0.2.14 修复验证 · 2026-11-01

> 更正：本轮的网页 alpha 检查未覆盖 Windows 桌面合成，实际小面板仍可能为不透明白底。已在 [0.2.15 的原生实拍验证与修复](RELEASE-0.2.15.md) 中纠正。

## 根因与处理

内容库的旧清理逻辑只匹配 `source.type=clipboard`，遗漏了截图与长截图；同时注释声称保留任务引用，代码却会解除任务中的引用。本轮统一按历史类型规划清理，保留固定项、任务引用、关联原图与文档，明确反馈删除及保留数量。清理图片时仅允许随序自己的 captures / clipboard-images 目录，保留外部原文件与仍被保留项共享的文件。本轮验证只清理独立测试数据，没有执行用户当前内容库的清空。

中转站 API 根地址及 `/v1` 可访问，真实模型列表包含 `deepseek-v4.1-flash`，用户配置却为 `deepseek-v4.1 flash`。使用当前保存的密钥，分别通过 Node 与实际 Electron `net.fetch` 调用获取模型并翻译固定测试短句，均成功。凭据不写入测试输出和发布产物。本轮新增模型列表选择、依据服务端列表的唯一匹配校正，以及成功后保存校正结果；用户在请求期间修改的模型设置不会被旧请求覆盖。

悬浮板背景减少底色覆盖；真实 Electron 透明截图在背景空白区域测得 alpha 29/255，窗口原生层保持透明并继续裁切圆角。键帽保持独立的较高覆盖底色，避免透明背景降低按键文字对比度。底部长驻提示隐藏，改为首次打开的非阻塞指南；关闭后保存状态，三点菜单可再次查看。

- `npm run verify:launcher` 通过：真实清理 IPC、任务内容保留、背景 alpha、首次指南持久化及原有搜索、绑定、全屏与快捷键回归。
- 中转站实际模型查询与翻译成功；仅使用固定测试文本，不发送用户文档或剪贴板正文。
- `node tools/packaged-markdown-check.js` 通过：实际 0.2.14 本地文件打开与保存、窗口稳定性及启动台流程。
- `node tools/release-package-check.js` 通过：94 个应用源文件与包内字节一致，更新源、安装器 CRC、大小与 SHA512 一致。
- `npm run screenshots` 更新真实产品界面，并验证独立窗口、圆角及任务栏边界。
- 已公开发布 [0.2.14](https://github.com/huihui200739/suira-updates/releases/tag/v0.2.14)，四个远端文件大小与 SHA256 摘要一致；真实匿名更新检查发现新版、完整下载通过 SHA512，当前版本返回已是最新版。测试未执行用户安装目录的覆盖更新。

第三方模型供应、密钥权限、额度与网络状态无法由客户端保证始终可用；遇到异常会给出可操作的失败原因。透明效果取决于实际后方窗口颜色：后面是白色工作台时仍会偏白。系统主动启用“减少透明度”时尊重其无障碍设置。
