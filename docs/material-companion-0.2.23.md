# 0.2.23 交付核对

本版保留 [0.2.22 的材质与伙伴实现](material-companion-0.2.22.md)，修正独立日历伙伴停在隐藏标题区域的问题，改用始终可见的紧凑顶栏。Markdown 和日历顶栏自动使用 28px，其他区域遵循 32/40 大小设置。

六类窗口已按真实控件尺寸、非零可见区域和视口边界重新检查通过；不再只检查 DOM 存在或图集加载。其余未改变的材质、38 键扫过、最小窗口控件、设置同步、保存举信和文档流程沿用上一版集中验证结果，未重复跑全套。

图集来自内置 image_gen，原始透明图与四格姿态已打包在 src/art/companion-courier.png；提示词和尺寸见 [生成记录](design/companion-generation.md)。没有运行时生成请求、持续循环动画或新的在线服务依赖。

修正前安装版检查发现日历不可见，未将失败算作通过；0.2.22 保留其公开版本记录，0.2.23 作为后续修复更新，不覆盖已发布的二进制。

背景仍是圆角安全的半透材质；当前 Windows 原生实时模糊尚未通过圆角安全门槛，本版没有重新启用。新的视觉层次来自分开的雾灰底板与乳白键面，不将普通透明称为实时背景模糊。

设计方法参考 Damir Sokolovsky 的 [unslop](https://github.com/heydamir/unslop)（CC BY 4.0）。

收尾已运行 npm run clean -- -IncludeObsoletePackages，清理 16 项、约 1103.5 MB 闲置测试缓存和旧构建；保留桌面 0.2.23 安装包、当前程序、依赖、有效测试源码和加密备份。此前被拒绝删除的旧运行备份未重试。
