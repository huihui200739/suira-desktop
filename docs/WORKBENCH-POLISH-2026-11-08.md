## 侧边栏设计

参考 [Notion 官方侧边栏说明](https://www.notion.com/help/navigate-with-the-sidebar) 中的显式收起/展开入口和 `Ctrl + \`。随序只有五个主入口，因此选择保留图标栏，而不是完全隐藏导航：

- 常规宽度 184px，收起后 64px；窄窗口展开宽度保持原来的 160px。
- 顶部按钮保持可见，图标箭头随状态变化；标题栏底色、品牌区域与正文使用同一宽度状态。
- 图标可直接切换任务匣、内容库、设置，日历和 Markdown 仍打开独立窗口。
- 所有入口有可访问名称，当前页面有 `aria-current`；收起后悬停/键盘聚焦显示名称。
- 按钮有 `aria-expanded`、操作提示与快捷键说明。编辑器、输入框、输入法合成和模态框不会被该快捷键打断。
- 使用本机 localStorage 记忆布局，在首帧前恢复；存储不可用时仍可正常使用。
- 尊重减少动态效果设置，不新增运行时依赖、不读取或上传用户内容。

## 已修复的确认问题

| 模块 | 问题与处理 |
| --- | --- |
| Markdown 草稿 | 保存第一个快照期间继续输入再切文档，会重置编辑器丢失末尾编辑。现在在切换前保存到最新修订，并保持 API 保存串行。 |
| Markdown 原文件 | 写回完成时使用可变 current，可能覆盖已切换文档的列表记录或把较新编辑误标为已写回。现在固定文档 ID/修订，只合并原文件元数据。 |
| 日历 | 保存等待期间改变表单日期会定位到未提交日期；无 submitter 的合法提交会访问空对象。现在使用提交快照且兼容空 submitter。 |
| 页面刷新 | 任务与内容库的迟到结果可能覆盖更新的数据；两页共用的内容状态现在有统一响应顺序。 |
| 拼音搜索 | 旧请求迟到、清空搜索后的旧响应、切换查询时旧匹配集合残留。现在立即清空旧匹配，并使过时响应失效。 |
| 剪贴板入匣 | 等待剪贴板读取期间切换任务，内容可能加入新的目标。现在固定点击时的任务，阻止重复提交并检查关联结果。 |
| 任务弹窗 | 空值可提交、重复提交、异步失败丢输入；现在保留失败输入且可重试。另区分写入成功与刷新失败，避免列表刷新失败导致重复创建。 |
| 历史清理 | 原先只保护部分旧式来源关联，可能移除保留内容依赖的上游。现在手动清理保护任务、固定项和保留文档的完整 parentIds/originItemId 来源链。 |
| 容量裁剪 | touchItem 更新记录时间但不移动数组，按旧下标截断可能移除刚再次复制的记录。现在按记录时间选择保留项。 |
| 数据读取 | 读取或解析失败被当作空库，后续保存可能覆盖原文件。现在只有首次 ENOENT 可正常创建，其余错误明确停止加载；失败重载还会阻止后续/排队写入，成功重载后才恢复。 |
| 动作与组合动作 | 动作失败后记录再次保存失败会再次 reject；组合动作最终提交异常没有统一捕获，取消后迟到成功仍可能被报告。现在返回明确失败/取消结果。 |

## 仍需明确的边界

- 不能把一次代码审查和回归测试称为“整个项目零 bug”。截图/长截图、多屏 DPI、输入法与全部硬件组合没有在本轮重新做全量人工验收。
- 本次保留原有自动保留期策略；完整来源链保护覆盖的是“清理历史记录”操作。更广泛的自动过期/来源保留策略仍应单独定义。
- 保存失败不保证所有内存修改事务回滚；未通过真实磁盘满、断电或多个进程同时写同一库进行验收。
- 取消操作不能撤销已经开始的外部副作用，只停止后续步骤和丢弃迟到成功状态。
- 加载失败会明确提示并保留文件，但尚未提供图形化备份管理、自动恢复向导。
- 0.2.44 是本地构建，尚未发布到公开更新源。安装器未代码签名；安装、升级、卸载流程本轮没有在真实用户安装上执行。
