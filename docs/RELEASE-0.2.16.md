# 0.2.16 半透明程度调整

0.2.15 修复原生合成后，原本很低的背景底色覆盖真正透到了桌面，导致后方图标、文字干扰面板。本轮保留原生透色机制，将默认窗口背景改为“柔和玻璃”，底色遮挡约 84%，并提供可保存的三档选择。

三点菜单 → 外观：柔和玻璃约 84% 遮挡、更通透约 62%、更强遮挡约 94%。仅调整小窗口背景，键位文字保持正常不透明，显示模式记忆继续保留。首次指南关闭后，本会话中延迟返回的初始化结果也不会重新打开它。

验证：

- 完整 `npm test` 通过。
- `npm run verify:launcher` 检查默认渲染 alpha 215/255，材质选择即时生效并在重启后保存；显示模式、搜索、绑定与菜单回归通过。
- 真实桌面合成检查：红／蓝背景采样分别为 `[217,201,209]`、`[194,209,229]`，颜色差缩小到 23 和 20，较前版明显减弱。测试设置差分上限，防止再次出现过度透明，也避免退回完全不透色。
- [复杂模拟消息背景实拍](product/panel-desktop-busy-blue.png)只包含测试窗口与演示文本，没有采集用户聊天内容或桌面。
- 安装包与 94 个应用源文件字节一致，更新元数据和安装包 SHA512 一致。
- 实际打包版本的文档、窗口稳定性和显示模式保存检查通过；当前产品截图与圆角检查已更新。
- 0.2.16 已公开发布，匿名版本检查与完整下载校验通过；当前版本正确显示已是最新版。
