# 快捷键与 Markdown 文件

## 默认从面板开始

0.2.4 的全局快捷键默认关闭。双击托盘图标打开面板，点击工具或按对应字母；原来的组合键配置会保留。侧栏「检查与配置快捷键」可检查并开启全局模式，开启前会提示其对其他软件菜单键的影响。

全选通常是 **Ctrl+A**。Alt+A 在不同软件里可能是菜单操作，也可以是用户自定义的组合键。

| 场景 | 响应规则 |
| --- | --- |
| 面板内输入框、输入法正在组合输入 | 优先输入，不将字母当成工具动作 |
| 面板内未在输入 | 字母、Alt+字母触发绑定工具；长按重复事件不反复触发 |
| 未启用全局模式 | 其他软件中的组合键由原软件处理 |
| 已启用全局模式 | 只响应成功注册的全局组合键；Alt+字母可能覆盖其他应用的菜单操作 |
| 本软件内专用唤起键与派生 Alt+字母重复 | 保留专用唤起键，停用重复派生键；面板中的点击与字母动作仍可用 |
| 全局键被系统或其他程序占用 | 显示注册失败，用户换键或自行取消另一软件的绑定；不强制接管 |

Ctrl+字母/数字、Windows 组合键及已知系统保留键不可设为全局快捷键。按住型唤起同样需要先成功注册，注册失败时不启动按键侦测。

## 检查范围

启动时检查本软件配置的组合键，也可手动重新检查。结果表示检查时能否注册为全局热键；其他软件之后启动或更改设置，结果可能变化。

Windows 没有统一列出所有应用内部快捷键或给某个软件设置“最高优先级”的接口。文件快捷方式、菜单键和应用内部按键也不等同于系统全局热键。检查不能保证与所有程序的内部操作毫无重叠，因此全局模式需要用户主动选择。

参考：[Windows RegisterHotKey](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-registerhotkey)、[Electron globalShortcut](https://www.electronjs.org/docs/latest/api/global-shortcut)。

## Markdown 默认打开方式

安装版向 Windows 注册 `.md` 与 `.markdown` 的打开候选，**不替换现有默认应用**。右键 Markdown 文件 →「打开方式」→「选择其他应用」→ 选择随序；按 Windows 提供的选项设为始终使用。便携版可通过「选择电脑上的应用」定位解压后的 `随序.exe`。

也可在 Windows 设置的「应用 → 默认应用」按文件类型选择，见 [微软默认应用说明](https://support.microsoft.com/en-us/windows/apps/change-default-apps-in-windows)。

支持 UTF-8 文本，单文件不超过 800 KB、正文不超过 20 万字符。中文及带空格的路径均可打开。程序已经运行时，新文件进入现有 Markdown 窗口。

- 自动保存保留本地加密草稿，不会每次输入都改写原文件。
- 保存按钮或 Ctrl+S 主动写回原位置。
- 如果原文件已被其他程序修改，会拒绝覆盖；草稿仍保留，可导出副本后比较。
- 关闭有改动的本地文档时，可以保存原文件、保留草稿后关闭，或取消关闭。
- 重新打开同一路径时优先恢复尚未写回的草稿。删除随序内的文档记录不会删除磁盘原文件。

随序内「打开 Markdown」与 Windows 打开方式使用同一套文件关联和草稿保护规则。若想放弃冲突草稿并重新载入磁盘内容，可先导出备份，再删除随序内该文档记录并重新打开文件。

不支持的文本编码会提示先转换为 UTF-8；没有写入权限、原文件被移动或外部修改时会保留草稿并报告错误。
