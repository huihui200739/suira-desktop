# 工作台与文档编辑 · 0.2.26

工作台承接截图、剪贴板、任务与写作。此次方向是稳定的桌面工作区：浅色磨砂侧栏、白色内容面、清楚的操作层次；彩色工具物件和柔光键帽仍属于悬浮板。去掉顶部重复的快捷键提示，任务内容通过留白与分隔线分组，设置保持统一的字段与按钮。

写作时，目录与正文各占明确区域，正文连续铺满不透明阅读底色。默认是可视化写作，另有源码、分栏和阅读模式。目录从当前文章的一级至六级标题生成，排除代码块，支持 Setext 标题、分节折叠和整个侧栏收起。

交互采用选区工具栏、右键菜单与斜杠插入。支持文字颜色、背景高亮、字号和基础格式，列表、待办、代码、表格及表格行列操作。链接与图片引用通过明确输入的地址插入；图片引用不会在打开文档时自动请求远程资源。

保存仍使用现有加密 Markdown 内容与原文件保存流程。打开可视化模式本身不改写原文；实际编辑后，基本结构保存为 Markdown，颜色和字号保存为允许范围内的内嵌 HTML 样式。预览、粘贴与导出共用白名单样式清理，移除活动 HTML、任意 CSS 和隐式图片加载。含 YAML、注释及未支持 HTML 的文章保留完整源码模式，避免转换损失。撤销历史按文档隔离，中文组合输入完成后保存。
