# 随序键位材质样稿

这轮用于确认工具图标、键帽和微交互方向，不替换安装版或生产界面。

用户确认该方向后，已在 0.2.19 接入正式悬浮板，并扩展为完整工具目录；本目录保留原始五键样稿以供设计对照。当前实现与验证见 [界面核对记录](../ui-polish-status.md) 和 [产品截图](../product/README.md)。

`keycap-study.html` 是可交互预览片段，供聊天内预览使用。`keycap-study.png` 是浅色默认状态截图。预览中的“当前样式对照”按现有截图的比例重绘，不是安装版窗口实拍。

- 五颗键：翻译 T、截图 C、日历 F、Markdown M、回到桌面 D。保留现有键位分配。
- 图标采用可缩放的分层图形，统一左上光源；工具使用蓝色、珊瑚色、琥珀色与钢灰色区分。菜单等通用控件不使用这些多色物件。
- 默认键帽包含 3px 底边；鼠标停留 120ms 后抬升 3px，倾斜最大 3°，图标额外抬升 1px。按压回落 2px，缩放为 0.98；移出约 180ms 归位。
- 名称和按钮点击区域保持不动。原生按钮支持焦点与空格/Enter；减少动态效果时关闭变换。
- 底部“默认 / 悬停 / 按下”是预览控件，仅用于对照翻译键状态；箭头切换新版与扁平样式。可通过预览调节控件调整抬升高度、倾斜幅度和立体反馈。
- 支持浅色、深色以及窄屏重排；托盘背景用于材质演示，不代表 Windows 原生桌面模糊实拍。

## 验证

2026-11-01 使用真实 Chrome 渲染并验证：五个工具图形、停留与倾斜、标签位置固定、按压、键盘激活、状态切换、减少动态效果、深色配色、360px 宽度无水平溢出、无脚本异常。已人工检查默认、悬停及窄屏截图。
