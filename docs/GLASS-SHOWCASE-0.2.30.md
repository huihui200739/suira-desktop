# 0.2.30 玻璃控件与仓库展示

全屏搜索、三点菜单、子菜单、工具箱和搜索结果移除旧的深蓝色覆盖，使用与窗口模式相同的玻璃令牌。搜索条 44px，更多入口保留无圆框按钮；浅色与深色菜单背景及文字颜色逐项比较一致。全屏应用名称不再使用白字阴影，分页沿用相同主题色。

速记保留原有真实 Windows acrylic 合成，移除 utility-surface 中覆盖背板和正文的不透明实色。标题栏、正文、底栏使用不同密度，正文保留 16px/1.7。自动保存、置顶、列表切换、最小尺寸和关闭行为不变。真实合成检查对红／蓝背景及黑白细条分别采样，验证透色、模糊和圆角，不使用用户桌面内容。

产品图从当前源码的独立演示实例生成。面板、速记使用受控背景原生采集，其余图展示真实 Electron 页面。README 明确说明采集方式；应用不会嵌入演示背景。测试背景需先完成绘制再揭示目标窗口，避免将上一帧背景误判为玻璃结果。

`docs/product/INTRO.md` 是两仓库产品介绍的唯一来源，版本取自 package.json。`tools/sync-showcase.js` 更新源码首页、公开说明，并且仅复制显式允许的产品文档、许可、图标与 9 张图片。源码仓库保持私有，公开仓库没有复制源码或私有历史。两仓库 About 使用同一介绍与正式下载链接。

公开仓库 14 个文件已通过匿名 GitHub 内容 API 核对，逐一比较远端 blob、大小与正常 Git 提交；图片验证为真实 PNG 内容。公开 main 与本地 checkout 相同且工作区干净。结果见 showcase-public-0.2.30.json，内容摘要见 showcase-0.2.30.json，仓库资料核对见 showcase-repositories-0.2.30.json。

验证通过：138 项 UI 接线、71 项浏览器渲染、40 项速记行为；真实窗口圆角、缩放、最大化、任务栏安全区域；全屏深浅配色一致性、菜单点击和外部收起；速记真实背景合成。安装包 118 个源码文件逐字节匹配，安装器 CRC、更新清单及摘要通过。
