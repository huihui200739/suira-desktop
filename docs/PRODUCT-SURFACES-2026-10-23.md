# 桌面浮层与底部剪贴板改版

本轮按用户提供的 Windows 面板和 macOS 浮引底部剪贴板截图调整。重点是横向比例、桌面融合与可用的内容浏览，不以改色替代窗口问题修复。

## 已实现

- 动作面板由 960×660 改为 1160×620 DIP，保留 38 个键位及绑定。键帽改为 72×56，拉开横向间距；最近内容与返回目标并排，避免挤压最后一行。640×480 时主体可以纵向滚动。
- 去除两块浮层的外围阴影留白；Windows 原生 HWND 按四角圆弧裁切，避免亚克力底层露出矩形；启用系统 acrylic，页面只叠加透光底色、细边缘高光与内部卡片。深浅主题和减少动态效果继续有效。系统材质能力取决于 Windows 版本。
- 剪贴板由 1000×210 改为最大 1600×310 DIP，跟随光标所在显示器，贴近工作区底部，避开任务栏；负坐标副屏、小屏均限制在工作区内。
- 石墨紫内容架、220 DIP 宽预览卡片、完整图片缩略图、类型色点、来源与时间、明确选中轮廓。图片使用 contain，不裁掉截图边缘。
- 搜索最近 120 条记录的文字、标题、文件名和来源；文字、图片、链接、文件、收藏分类可组合搜索；收藏接入真实持久化接口，完整内容库入口可继续查找更早内容。
- 保留滚轮横向浏览、方向键/Home/End、双击/Enter 粘回原窗口与失败提示；新增 Ctrl+F 搜索、显式关闭、收藏和提交按钮。输入框方向键不再误换卡片，按钮 Enter 不会被全局粘贴拦截。重开重置筛选、搜索与提示。
- 顶部文件暂存继续默认隐藏，普通悬停和文字拖动不会唤出；文件进入才出现，拖离后隐藏。

## 验证与预览

- `npm test` 全量回归通过。
- `node tools/clipboardbar-check.js --preview`：93 项断言，包含搜索、组合筛选、收藏成功与失败、取消收藏、输入焦点、重开重置，以及 464×310 / 720×210 紧凑布局。
- `node tools/panel-shot.js`：浅深色 1160×620、800×560、640×480 的键位布局和既有异步错误路径。
- `test-display.js`：34 项几何检查，新增底部内容架和原生四角裁切。
- 当前运行实例通过真实 Electron/preload/IPC 检查；1707×1019 DIP 工作区上，动作面板 1160×620、72 DIP 键帽，剪贴板 1600×310；实际原生窗口已启用 acrylic，已用桌面合成截图检查外围底板。
- 已复查真实顶部暂存窗口的隐藏/文件拖入/拖离行为，没有改动或清空用户历史与暂存内容。

## 参考图中仍未覆盖的能力

自定义工作/个人分组、颜色类型、卡片批量操作尚未实现；录屏、长截图等原有规划键位继续标记为未实现。本轮解决这两块浮层的视觉与交互，不能据此称整个产品已与原版功能齐平。
