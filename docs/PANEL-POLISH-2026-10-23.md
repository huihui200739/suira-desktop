# 面板加宽与问题修复

参考对象是 macOS「浮引」，本仓库继续实现 Windows 版随序。现有模型是数字/符号 12 键与字母 26 键，共 38 键，本轮保留键位与动作映射。

## 界面变化

- 默认窗口从 744×644 调整为 960×660 DIP，键帽从 48 增至 60，键距从 8 增至 12；边缘留白随窗口宽度适配。
- 搜索框改为内嵌材质，工具箱增加选中状态，键帽补充渐变、高光、底边阴影和键盘焦点反馈。
- 应用图标与文字稍放大；工具箱统一卡片间距；宽屏翻译采用左右对照，小屏保留上下布局。
- 深浅色使用共享光影令牌；遵循减少动态效果设置。
- 主进程按当前工作区限制尺寸与位置，修复低高度屏幕下窗口底部越界。小屏仅主体纵向滚动，底栏不被裁切。

## 修复

- 搜索使用请求版本号，慢的旧查询不能覆盖新查询；清空时取消待发请求并失效在途结果。
- 输入搜索词后立即移除旧候选，避免 Enter 执行上一轮结果；候选最多保留实际展示的 12 条。
- 搜索加载、无匹配与接口失败分别展示；工具箱与搜索结果不叠放。
- 输入框 Esc 不再冒泡后二次触发；第一次清空搜索，之后返回动作或收起面板。
- 应用列表加载失败提供原因与重试；应用启动、OCR/翻译保存、工具调用的 Promise 拒绝转为可读提示。
- 错误 toast 正确使用 `is-error` 样式。
- 重翻译只采用最新目标语言的结果；关闭后迟到的请求不覆盖面板；重开面板关闭旧结果并清除旧提示。

## 验证

- `npm test`：全量核心逻辑、页面渲染与交互回归通过。
- `npm run test:panel`：真实页面 + 可控制延迟/失败的接口 fixture，覆盖 Esc、搜索竞态、翻译竞态、重试、启动/保存拒绝与重开状态。
- 布局覆盖 960×660 浅/深色、800×560 浅色、640×480 深色。均无横向溢出，底栏可见；小屏滚动后最后一行键帽可完整看到。默认尺寸无纵向滚动。
- `SUIRA_CDP_PORT=9315 node tools/electron-panel-check.js`：独立数据目录启动的真实 Electron，真实 preload 与 IPC；读到窗口 960×660、60 DIP 键帽、38 个键位，无横纵溢出，并核对当前工作区内的位置。
- `node tools/panel-shot.js`：更新 12–15、21–22 预览图；截图中的示例内容与翻译是 fixture，不代表真实 OCR 或翻译引擎输出。

## 范围

本轮没有新增录屏、长截图等规划功能，仍保持未实现状态。未在 macOS 原版中进行逐像素比对；本轮修复范围是已有 Windows 面板的尺寸、质感及上述可复现问题。已运行的旧实例需要退出托盘应用后重新 `npm start`，才会加载新的主进程尺寸。
