# 0.2.37 接力条验收

“下一步”在截图识别框、文字工具结果、剪贴板条、钉图右键菜单和速记更多菜单复用同一组件。常用三个动作直接显示，完整列表支持搜索与 Ctrl+K；1–9 在非文字输入区域执行对应动作。派生结果可以继续接力，迟到的结果不会替换新编辑。

新增动作：

- `text.to-note`：先保存已打开速记的待写入编辑，再按最近编辑时间追加；超出 2 万字时拒绝追加并保留原文。
- `text.to-markdown`：先保存当前文档，再追加。没有打开的文档时复用当天的“今天 · YYYY-MM-DD”文档。
- `text.to-calendar`：支持年月日、月日、今天／明天／后天、周／星期／礼拜，以及数字或中文时刻。只生成日程草稿，用户明确保存后才写入日历；无法识别时提示手动选择日期。
- `text.pin`：原样显示文字，支持选择、复制、缩放、透明度与另存为。按住 Ctrl 可从文字区域拖动窗口。

Markdown 源码与可视化菜单均可截图、截图提字，使用框选前保存的光标范围返回。截图期间文档发生变化时拒绝插入到旧位置；取消保持原文。图片使用应用内图片引用，可打开原图；作为文档附件保留，不随普通历史自动过期。

验证全部通过：

- `npm test`，包含日期解析与四个新动作的单测。
- `npm run verify:notes`：16 项。
- `npm run verify:workspace`：日历、文档、自动保存与窗口工作流。
- `npm run test:clipboardbar`：123 项。
- `npm run verify:documents`：真实编辑器与源码／写作模式。
- `npm run verify:relay`：真实 Electron／IPC 下验证五处入口、未保存内容保护、日程取消与明确保存、文字钉图、图片与英文剪贴板动作、源码和写作光标插入、截图取消、Ctrl+K、数字键、结果框的快捷键归属与迟到结果保护。详见 [机器记录](relay-0.2.37.json)。
- `npm run screenshots`：产品截图及文字工具、处理轨迹回归。
