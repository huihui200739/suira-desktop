# 统一浮层、区域录屏与钉图菜单

## 本轮交付

### 共享视觉与动效

- 以现有悬浮面板为基准，剪贴板栏、截图工具栏/提字窗口、文件暂存、速记、钉图及录屏使用同一套主题变量。
- 移除剪贴板固定深灰紫色、截图独立常暗色阶。浅色和深色均跟随设置切换。
- 浮层统一 24 DIP 圆角，与 Windows 原生窗口裁切一致；输入框、玻璃控件、文字和分类强调色共用语义变量。
- 控件反馈 120ms、一般过渡 180ms，小弹层 140ms；状态和操作先完成，动画不锁输入。减少动态效果设置下关闭过渡。
- 主窗口延续既有页面结构与配色，仅共享基础样式；本轮没有重构其信息架构。

### 区域录屏

面板 **S**、工具箱「录屏」或搜索「录屏 / luping / record」进入框选。按 Enter 确认后显示控制条，用户再点击开始。

- 可选 3 秒倒计时和系统声音，默认静音、不申请麦克风。
- 暂停/继续、结束、录制时间显示。关闭正在录制的控制窗或退出应用时先保存。
- 根据所选屏幕实际视频像素裁剪区域，支持 DPI 缩放和负坐标显示器；跨屏选区明确提示重新选择。
- 视频按块顺序写盘，避免将整段录制保存在内存。成功后输出 `.webm`，可播放、定位、另存为。
- 默认目录为用户数据目录下的 `recordings/`；非空中断文件保留为 `.partial`，不会当作完成视频展示。
- 控制条尽量放在选区外，并使用 Windows 内容保护接口从采集画面中排除。该系统能力的具体表现取决于 Windows 版本和采集后端。

### 钉图菜单

- 独立 `pin.html/css/js`，不再把界面和样式拼在主进程字符串中。
- 图片右键或工具条「更多」：复制、另存为 PNG、恢复大小/透明度、切换置顶、临时收起、关闭。
- Ctrl+C / Ctrl+S，方向键浏览菜单，Esc 收起菜单或关闭图片。
- 保留拖动、滚轮缩放和透明度；收起/恢复保留之前透明度。分数 DPI 下允许窗口尺寸出现 1 DIP 舍入。

## 参考与选择

根据用户授权进行了 X 的公开检索。可访问结果主要为索引摘要，没有把未能观看的演示视频记作已验证参考。实际采用的原则来自作者公开页面：

- [Emil Kowalski：You Don't Need Animations](https://emilkowal.ski/ui/you-dont-need-animations)：高频工具应优先直接响应；此次保留短按压、选择和弹层反馈，不给快捷键操作加等待。
- [Emil Kowalski：Good vs Great Animations](https://emilkowal.ski/ui/good-vs-great-animations)：弹层的方向、起点与缓动应帮助解释交互。
- [Rauno：Craft](https://rauno.me/craft)：作为细节和控件质感的视觉参考；没有引入动画框架或逐帧后台装饰循环。
- [Electron desktopCapturer 官方文档](https://www.electronjs.org/docs/latest/api/desktop-capturer)：录屏使用受限的屏幕源请求与系统声音回环。

## 验证

- `npm test`：原有核心、UI、交互和渲染回归。
- `node test-recording.js`：选区校验、负坐标/跨屏拒绝、并发开始互斥、顺序写盘、停止等待尾块、空文件清理、取消和中断保留。
- `npm run verify:recording`：独立临时数据目录，真实 Electron 屏幕采集与本地测试图案。验证暂停/继续、停止、WebM 文件与解码；150% DPI 下 400×240 DIP 输出 600×360 像素，左右颜色正确。
- 真实系统声音请求返回视频和音频各一条轨道；倒计时期间取消不留下录制文件。
- 钉图真实图片加载、右键菜单、位图复制、置顶切换、收起恢复通过。
- `node tools/recorder-live-check.js --preview` 生成浅色/深色实际界面截图；预览内容均为测试数据。测试后恢复原剪贴板。

## 仍未完成

长截图、独立边缘入口、键帽动作绑定右键、壁纸、独立改图、日历和 Markdown 仍保留未完成状态。录屏尚未包含摄像头画中画、麦克风混音、光标高亮、键盘提示或 MP4 导出。本轮没有把这些能力标记为已实现。
