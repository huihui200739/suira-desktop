# 改图：本地图片标注与导出

## 入口

- 动作面板默认 `I`，也支持工具箱和搜索“改图 / gaitu / image edit”；改键与拖动沿用统一绑定模型。
- 独立窗口点“打开图片”或按 `Ctrl+O` 选择本地文件，也可直接拖入文件、按 `Ctrl+V` 粘贴图片。
- 剪贴板历史的图片卡片有“编辑”按钮，直接进入该图编辑，不执行粘贴；底部也可编辑当前选中的图片。
- 内容库与任务匣图片的“编辑图片”按钮打开同一个编辑器。
- 空工作台原位载入第一张图；已有图时，新导入的图片另开窗口，保留已有标注。

## 编辑与导出

与截图共用画笔、矩形、箭头、文字、马赛克、序号、颜色、撤销和重做。快捷键沿用截图工具栏，悬停图标可查看。

- `A` 进入裁剪，拖出新选区或调整边缘；`Ctrl+A` 恢复全图，保留标注。
- 绿色勾 / `Enter` / `Ctrl+C` 复制位图并保存到内容库。
- 保存图标 / `S` / `Ctrl+S` 另存为 PNG。取消对话框不会新增文件或内容记录。
- 钉图和提字同样使用编辑后的图片。复制、保存后窗口保留，可以继续编辑。
- 大图适应窗口预览，按原始像素合成导出；裁剪输出对应的原图像素区域。透明 PNG 保留透明通道。
- 输出是独立文件，不覆盖本次编辑的原图；别名、硬链接及补齐 `.png` 后与原图相同的路径也会被拦截。
- 历史图片的编辑结果通过 `parentIds` / `originItemId` 关联输入，原条目保留。

## 当前边界

支持 PNG、JPG/JPEG、WebP、BMP 输入，当前只输出 PNG。输入上限为 64 MB、单边 16384 像素、总像素 4000 万；超出范围显示原因。尚不支持图层工程文件、滤镜、任意旋转或跨次恢复未导出的标注。

PNG/JPEG 使用 Electron 原生解码，WebP/BMP 使用 Chromium 解码后固定为位图，预览与导出使用同一帧；相关接口限制见 [Electron nativeImage 文档](https://www.electronjs.org/docs/latest/api/native-image)。已在本机逐种格式载入并检查实际导出尺寸。

## 验证

最终 `npm test` 完整回归通过，以下改图专用检查也已通过。

- `npm run test:image-editor`：17 项，涵盖文件有效性、尺寸上限、原图/硬链接保护与面板动作语义。
- `npm run verify:image-editor`：独立 Electron 用户目录，隔离系统剪贴板、全局快捷键和文件对话框，运行实际 preload、IPC 和图片合成代码。
- 实测 1800×1000 图像的真实鼠标标注、窗口缩放、裁剪与恢复全图、另存取消、原图保护、PNG 落盘、内容库派生关系、复制调用、拖放、粘贴与透明通道。
- 剪贴板真实 DOM 回归包含历史图片编辑按钮、失败反馈，以及点编辑不触发粘贴；其余截图与面板回归继续运行。
- 顺手修复重复启动时访问已销毁主窗口的问题：从托盘闲置回收后再次启动，会重新创建主窗口。
