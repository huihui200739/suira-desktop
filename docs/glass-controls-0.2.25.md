# 0.2.25 界面收尾

方向沿用已确认的实时玻璃托盘、柔光键帽和彩色工具物件。此次集中解决控件表面过厚、多个选中底色叠加，以及背景变暗后文字难读的问题，不改变原生窗口实现。

工作台空详情不再铺满白底；侧栏、任务与设置容器使用薄透色层。主按钮、次要按钮、内容卡实际操作按钮、筛选标签、设置字段、Markdown 工具栏、日历入口与分段按钮共用材质。内容正文仍有更稳定的阅读面。

验证：

- `node tools/glass-controls-check.js`：实际 Electron 页面，隔离加密数据，检查任务空状态、内容卡操作、筛选、设置字段、Markdown 与日历动作、键盘焦点和无壁纸背景。
- 浅色主题叠黑色测试底、深色主题叠白色测试底，Markdown 活跃文本的保守对比度为 4.56–6.20:1。计算只取玻璃底层，不依赖局部亮面提供对比；禁用动作不计入活跃文本。
- 三张 `docs/product/glass-controls-0.2.25-*.png` 使用纯色合成测试底，只用于检查 CSS 层次与对比，不是原生桌面玻璃效果图。没有抓取用户屏幕或数据。
- UI 接线 138 项、渲染与交互 71 项、日历与 Markdown 数据模型检查通过。

本版没有更改原生背景、系统圆角或最大化逻辑；这些由 0.2.24 的系统合成验证覆盖。打包成品另以独立数据运行，面板、Markdown、日历、剪贴板的原生材质、偏好切换、图标与伙伴加载通过；安装包的 107 个源文件一致性、归档 CRC 和更新 SHA-512 检查通过。
