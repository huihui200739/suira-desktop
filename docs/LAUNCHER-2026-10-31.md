## 直接可用的变化

- 应用：移除每个软件外围的玻璃卡片，保留真实 Windows 图标、名称与清晰的悬停／键盘焦点反馈。默认页的四行全部可见。
- 展示：右上角「全屏／窗口」或 F11 切换。全屏展示覆盖当前指针所在显示器，Esc 先退出搜索或弹层，再返回窗口；窗口居中并避开任务栏。收起再唤起和重启保留选择。
- 绑定：点击空键或右键键位，选择「应用」。输入中文、拼音全拼或首字母，使用方向键、Enter 或鼠标绑定。显示名称与路径分别保存，绑定后的键位也显示软件图标。
- 补充入口：「重新扫描」刷新开始菜单索引；便携应用或未加入开始菜单的软件仍可通过「从文件选择其他应用」绑定。
- 搜索：应用模式只展示软件；动作模式的综合搜索继续提供工具、任务与内容。应用使用真实图标，其他结果使用类型图标，图片摘要不再直接堆放缓存文件路径。
- 工具箱：全部现有工具改为透明方块，使用 SVG 图标与少量分类色，不再用单字代替图标；默认尺寸下完整展示全部工具。

## 可靠性处理

应用图标在列表、搜索、绑定弹层与自定义键位之间共用缓存，按需读取并原地更新，不因图标到达而重排结果或抢走输入焦点。查询改变立即移除旧的可绑定选项，关闭或返回后的迟到响应不能重新打开列表；输入法选词时 Enter 不会执行绑定。失败会保留菜单并提供重试。

Windows 下透明、无厚边框窗口的 Electron 45 全屏实现只调整边界，`isFullScreen()` 并不可靠，见[对应源码](https://github.com/electron/electron/blob/v45.0.0/shell/browser/native_window_views.cc)。因此本轮明确保存启动台的展示模式，并按显示器边界展示，而不依赖错误的全屏状态回读。它是 Windows 无边框全屏启动台，不创建 macOS 的独立空间。

应用索引仍扫描当前用户与所有用户的开始菜单，不做全盘扫描。未创建快捷方式的程序使用手动选择入口；没有声称能发现所有便携软件。原有全局快捷键冲突策略保持有效。
