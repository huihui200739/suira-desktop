# 2026-10-25 交互改进

## 钉图与剪贴板

- 钉图收起后可按住胶囊直接拖动，松手不会误展开；单击仍可展开，展开保留移动后的坐标与原图窗口尺寸。
- 记录逻辑窗口尺寸，避免高 DPI 下多次收起、展开累计放大。
- 剪贴板纵向滚轮转换为横向位移，速度提高至原来的 2.8 倍；即时累计每次滚动，避免平滑动画吞掉连续滚动距离。横向触控板仍使用原生滚动。

## 界面与图标

- 绑定菜单宽度为 208 DIP，共用悬浮面板的玻璃材质、明暗主题；分类使用简洁线条图标，内置工具采用紧凑列表。
- 菜单靠近操作键位显示，靠近窗口边缘时自动调整位置。
- Windows 资源图标优先请求 256 像素，ICO 也使用原生多尺寸提取，保留比例与原始细节；旧 64 像素缓存切换至新版本。源文件本身分辨率不足时仍受原图限制。
- 原生接口依据 [Microsoft SHDefExtractIconW 文档](https://learn.microsoft.com/en-us/windows/win32/api/shlobj_core/nf-shlobj_core-shdefextracticonw)，提取后释放图标句柄。

## 截图工具栏按键

这些按键在截图覆盖层内生效，直接显示在对应按钮上；文字输入、输入法组合和结果面板不会误触发工具切换。

| 按键 | 功能 |
|---|---|
| A | 选区 |
| P | 画笔 |
| R | 矩形 |
| L | 箭头 |
| T | 文字 |
| M | 马赛克 |
| N | 序号标记 |
| C | 打开或关闭颜色面板，打开后按 1–6 选颜色 |
| Z / Ctrl+Z | 撤销；Ctrl+Y / Ctrl+Shift+Z 重做 |
| Q | 钉图 |
| S / Ctrl+S | 另存为 |
| O | 提取文字 |
| Enter / Ctrl+C | 完成并复制 |
| Esc | 关闭当前颜色/结果面板；否则取消截图 |
