工具与复现

REA 使用官方 npm 注册的 rea-agents@6.7.0，安装在 research/rea-tool，未执行全局 setup。Node 为 24.19.0。Git clone 因 HTTP/2 传输错误失败；仓库 README 与相关说明通过官方 GitHub 地址读取，实际分析使用版本固定的 npm 包。不能把 npm 包分析描述为已经审计完整仓库源码。

在工作区根目录运行：

NODE_BIN=/Users/huihui/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node
REA_CLI=research/rea-tool/node_modules/rea-agents/scripts/rea.mjs
"$NODE_BIN" "$REA_CLI" inspect-artifact /Applications/浮引.app --format json
"$NODE_BIN" "$REA_CLI" inspect-macho /Applications/浮引.app --format json

补充使用 plutil、file、otool -L、nm -arch arm64 -nm 和 strings -a；原始输出保存在 research/evidence/。
